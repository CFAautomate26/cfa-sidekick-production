What this is

The standards model is the store's own list of what good looks like: the values and standards, a short definition of each, and a description of each of four levels, lowest first. Leader reviews rate each standard against those descriptions, and hiring scorecards can borrow them, so everyone is measured against the same written words.

Reviews and hiring scorecards need a model before they can start. {% if viewer.is_operator %}Load the store's file below. The example file shows the layout.{% else %}The Operator loads it.{% endif %}
