# Legal Updates — the Alerts Function

Mirrors e2r's "Alerts" service: proactive notice of Ontario employment-law
changes that affect the store, so compliance changes get made before a
complaint or inspection forces them.

## How to run a briefing

Ask in any session: **"run a legal update briefing."** The session should:

1. Search current sources (Ontario.ca ESA guidance, Ministry of Labour
   announcements, new *Working for Workers* legislation, notable ONCA/ONSC
   employment decisions, HRTO/OLRB trends) for changes since the
   **last-briefed date** below.
2. Report only what is *actionable for this store*: rate changes, new
   obligations, new deadlines, doctrine shifts that change the templates or
   playbooks.
3. Update the affected documents in this folder in the same session, and
   update the change log and last-briefed date here.

Standing cadence worth keeping: **every September** (October 1 minimum wage
change lands then) and **every January** (most ESA amendments take effect
Jan 1).

**Last briefed: August 2026** (framework creation baseline).

## Known upcoming / recurring changes to watch

- **Every Oct 1**: Ontario minimum wage indexation (general + student rates).
  Update [ontario-employment-standards.md](./ontario-employment-standards.md)
  and check anyone within $0.50 of the new floor, including wage compression
  above it.
- ***Working for Workers* act series**: Ontario has amended the ESA nearly
  annually since 2021. Watch for the next act each session of the
  Legislature.
- **Federal changes** generally do not apply (the store is provincially
  regulated), but EI rule changes affect ROE handling.
